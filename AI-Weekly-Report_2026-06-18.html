Executive Summary

今週最大のニュースは SpaceXによるCursorの600億ドル買収（6/16） と、トランプ政権によるAnthropicのFable 5・Mythos 5モデルへの輸出規制（6/12） の2件。前者はAI×宇宙テックの融合加速を示し、後者はAIモデルが初めて輸出規制対象となった歴史的先例となった。

G7サミット（6/15〜17、フランス・エビアン）ではAIの国際標準フォーラム設立が議論され、欧米・日本間の規制アプローチの差異が浮き彫りになった。

ツール面では Claude Code が3バージョン（v2.1.178〜181） をリリース。Tool(param:value) によるきめ細かい権限制御や /config のインライン設定変更など、大規模エージェント運用を意識した改善が際立つ。

国内技術コミュニティでは Loop Engineering（AIエージェントを自律ループで動かすパラダイム）が爆発的に拡散し、Zenn・Qiita・DevelopersIOで多数の実装記事が掲載された。

2026-06-17
v2.1.181
新機能 3件 改善 6件 修正 30+件

新機能

  • /config key=value 構文の追加 — インタラクティブ・-p・Remote Control すべてで有効。設定変更をコマンド一発で完結。
  • sandbox.allowAppleEvents — macOS でサンドボックス内コマンドが Apple Events を送信可能に。
  • CLAUDE_CLIENT_PRESENCE_FILE 環境変数 — マーカーファイルを指すと在席中のモバイルプッシュ通知を抑制。
実務インパクト：/config thinking=false のように推論モードをその場で切り替えられるため、デバッグ中の高コスト推論を即座に止められる。

改善

  • Bun ランタイムを 1.4 にアップグレード
  • 長いパラグラフのストリーミング改善（行ごとに逐次表示）
  • API 接続断の自動リトライ（thinking 中の切断も対象）
  • サブエージェントパネル：30秒後に自動非表示、最大5行表示
  • MCP OAuth ブラウザページのスタイル改善・成功後の自動クローズ
  • フルスクリーンモードのURL開封に Cmd+click（macOS）/ Ctrl+click を要求
実務インパクト：長時間セッションでの接続断が自動復旧されるため、夜間・長時間バッチ処理の信頼性が大幅向上。

主要バグ修正（抜粋）

  • カスタム ANTHROPIC_BASE_URL / Foundry でプロンプトキャッシュが読み込まれない問題
  • ネットワークドライブ・クラウド同期フォルダで Write/Edit が 0 バイトになる問題
  • macOS で open / osascript が error -600 で失敗する問題
  • 新鮮な環境で起動に余分な ~120ms かかる性能回帰
  • 劣化ネットワークで最大 15 秒間ターミナルが空白になる起動ブロック
  • macOS で Spotlight が再インデックス中に TUI がフリーズする問題
  • 30日トランスクリプトクリーンアップ中に長期アイドルセッションが履歴を失う問題
  • AskUserQuestion マルチセレクトで "Other" の入力が黙って落ちる問題

輸出規制 安全保障
2026-06-12
トランプ政権がAnthropicに輸出規制命令。Fable 5・Mythos 5 の全外国人アクセスを停止。 商務省が「別の企業が Mythos をジェイルブレイクした」との報告を受け、Fable 5・Mythos 5 を商業AIモデルとして初の輸出規制対象に指定。Anthropic は対応中に全ユーザーへのアクセスを一時停止。
出典：Axios｜Nextgov/FCW
商業展開済みAIへの輸出規制は史上初。今後フロンティアモデルが「デュアルユース兵器」と同等に扱われる前例となる可能性があり、グローバルなAI製品のリスク評価が根本的に変わる。

政策 ホワイトハウス
2026年6月（正確日付未確認）
