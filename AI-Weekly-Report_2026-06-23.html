Executive Summary

本週最大のニュースは SpaceX によるAIコーディングスタートアップ Cursor の600億ドル買収合意（6月16日）。同社 IPO 直後のディールは史上最大のベンチャー買収として注目を集めた。

Claude Code は5バージョン（v2.1.179〜v2.1.186）を連続リリース。オートモードで危険な git コマンドをブロックするセーフガード（v2.1.183）や、MCP サーバーの CLI 認証コマンド（v2.1.186）が実装された。

Anthropic は韓国・ソウルオフィスを開設（6月17日）し、NAVER・Samsung SDS・LG CNS ら大手との連携を発表。一方で米輸出規制により最新モデル（Mythos 5/Fable 5）の外国人アクセスが制限されるという矛盾した状況が続いている。

Claude Fable 5 は6月22日をもって Pro/Max/Team/Enterprise プランの無料アクセス窓が閉じ、6月23日以降は使用クレジットが必要になった。GPT-5.6・Gemini 3.5 Pro GA がいずれも6月末に迫っており、モデル競争が最高潮を迎えている。
