エグゼクティブサマリー

今週は Claude Code が5バージョン（v2.1.178–v2.1.185）をリリース。自動モードの安全強化（破壊的 git コマンド・IaC 破壊コマンドのブロック）が最大トピック。

OpenAI は $150M 投資のパートナーネットワークを6月14日に発表し、企業導入加速を宣言。Codex CLI は v0.141.0 で安全な暗号化リレーと音声制御を追加した。

M&A では SpaceX が Cursor（Anysphere）を $600億 の株式交換で正式合意（6月16日）。AI コーディングツール市場が宇宙産業と合流する歴史的取引。

Anthropic は ソウルオフィスを開設（6月17-18日）し、NAVER・Nexon・Samsung SDS・LG CNS など韓国大企業が相次いで Claude Code を採用。Google は Gemini CLI を Antigravity CLI へ移行すると発表。

AI人材流動では Google Gemini 共同リード Noam Shazeer が OpenAI へ移籍（6月18日）。Transformer 論文共著者の移籍は業界に大きな衝撃を与えた。

v2.1.185 2026-06-20 改善

✦ UX 向上：誤検知が半減し、低速回線での不要な不安が軽減。
v2.1.183 2026-06-19 新機能 改善 修正
新機能 — attribution.sessionUrl 設定を追加。コミット・PR への Claude セッションリンク付与を無効化できる。
✦ 企業ポリシー対応：クローズドプロジェクトで URL の外部漏洩を防止。
新機能 — /config --help でショートハンドキー一覧を表示。
✦ 学習コスト削減：設定キーをリファレンスなしに確認可能。
改善（重要） — Auto モードの安全強化。① git reset --hard / git checkout -- . / git clean -fd / git stash drop を明示的要求なしにブロック。② git commit --amend を「今セッションでエージェントが作成していないコミット」へのブロック。③ terraform destroy / pulumi destroy / cdk destroy を特定スタック指定なしにブロック。
✦ 生産性×安全：意図しないデータ消失・インフラ削除を防ぐ業務安全ネット。
改善 — 非推奨モデル使用時に stderr（print モード）と agent frontmatter 両方で警告を表示。
✦ 移行スムーズ化：API 移行忘れを早期発見。
修正 — 起動時の空白ターミナルフリーズ（最大15秒）、macOS Spotlight 再インデックス中の TUI フリーズ、サブエージェントの無制限ネスト（5階層上限に統一）ほか多数。
✦ 安定性向上：起動体験とリモートセッション信頼性が改善。
v2.1.181 2026-06-17 新機能 改善
新機能 — /config key=value でプロンプトから直接設定変更（例：/config thinking=false）。
✦ 操作効率化：設定ファイルを開かずに即座に切り替え可能。
新機能 — sandbox.allowAppleEvents opt-in 設定（macOS）、CLAUDE_CLIENT_PRESENCE_FILE 環境変数でモバイル通知を抑制。
✦ 柔軟な通知管理：CI/CD 環境や集中作業時のノイズ削減。
改善 — バンドル Bun ランタイムを 1.4 へアップグレード。長い段落ストリーミングを行単位で逐次表示に変更。API 接続が思考中に切断された際の自動リトライを改善。サブエージェントパネルを30秒後に自動非表示・最大5行スクロールに。
✦ 応答体験の向上：長文回答が逐次表示になりタイムアウト耐性も向上。
v2.1.179 2026-06-16 修正

✦ 安定性：WSL2 ユーザーと長文タスクの使いやすさが回復。
v2.1.178 2026-06-15 新機能 改善

✦ 権限制御の精度向上：モデル・パラメータ単位で承認範囲を絞り込み可能。
新機能 — ネストされた .claude/skills ディレクトリから修飾名でスキルを自動ロード。Auto モードのサブエージェント評価をローンチ前に実施するよう改善。
✦ 大規模プロジェクト対応：スキルのモジュール化・名前空間管理が容易に。
修正 — Chrome OAuth 接続失敗、メモリリーク（stale WebSocket/OAuth ディスクリプタ）を修正。
✦ リモートセッションの信頼性向上。

2026-06-16 SpaceX、AI コーディングツール Cursor を $600億で正式買収合意

宇宙産業と AI コーディングツールの融合は異色に見えるが、Elon Musk の「人型ロボット × AI コード生成」構想との整合と見られる。Cursor の競合（GitHub Copilot、Claude Code）への対抗上、巨大なコンピュート・資本力が背景に。

財閥グループを含む韓国大手の同時採用は Anthropic のアジア太平洋戦略の最大成果。日本・韓国市場でのエンタープライズ浸透が今後加速すると見られる。
