1. Claude Code / Codex 機能追加

期間内リリース 5件

① Claude Code（Anthropic） — v2.1.176 〜 v2.1.183

v2.1.183 2026-06-19
新機能
  • /config --help でショートハンドキー一覧を表示
    設定変更の学習コストを削減。使えるキーをその場で確認できる。
改善
  • auto mode 安全性強化：未指示の破壊的コマンドを自動ブロック
    ブロック対象：git reset --hard、git checkout -- .、git clean -fd、git stash drop、terraform/pulumi/cdk destroy。エージェントが誤ってデータを消す事故を防止。
  • /config トグル動作を改善（Enter/Space で変更、Esc で保存終了）
    設定画面の操作が直感的になり、誤操作リスクが減る。
修正
  • thinking.disabled 時の 400 エラー修正 / WebSearch サブエージェントの空結果問題 / Windows Terminal での全画面 TUI 破損 / MCP 認証時の auth-stub ツール露出
    Windows 利用者・MCP 利用者の安定性が向上。
v2.1.181 2026-06-17
新機能
  • /config key=value 構文：プロンプトから任意設定を即変更
    例：/config thinking=false。設定ファイルを開かずにチャット内で設定切り替えが可能に。
  • CLAUDE_CLIENT_PRESENCE_FILE 環境変数：マーカーファイルで mobile push 通知を抑制
    CI/CD など無人実行時に不要な通知を止められる。
  • sandbox.allowAppleEvents 設定：macOS サンドボックスで Apple Events 送信を許可
    macOS のアプリ間連携（スクリプト自動化）をサンドボックス内から実行可能に。
改善
  • Bun ランタイム 1.4 へアップグレード / 長文ストリーミングを行単位で逐次表示
    起動速度・レスポンス表示速度が体感向上。
  • サブエージェントパネルの UX 改善：30 秒で自動非表示、最大 5 行、キーボードヒント追加
    マルチエージェント使用時の画面が整理され視認性向上。
修正
  • ネットワークドライブ / cloud-synced フォルダでの Write/Edit 0 バイト問題 / macOS Spotlight reindex 時フリーズ / 起動時レグレッション（120ms/起動）修正
    OneDrive・Dropbox 上のプロジェクトでのファイル書き込みが正常化。
v2.1.178–179 2026-06-16/17
新機能
  • Tool(param:value) 構文によるパラメータ付き権限ルール
    例：Agent(model:opus) で Opus モデルのサブエージェントのみをブロック可能。細粒度の権限管理が実現。
  • ネストされた .claude/skills ディレクトリ対応：ディレクトリ名で名前衝突を回避
    モノレポや複数プロジェクト混在環境でのスキル管理が容易に。
改善
  • auto mode でサブエージェントスポーン前に classifier が事前評価
    不正なサブエージェント呼び出しを早期検知し、セキュリティが向上。
修正
  • mid-stream 接続切れ時の部分レスポンス保全 / WSL2 マウスホイールスクロール修正（Windows Terminal・VS Code）/ スピナーフリーズ修正
    WSL2 開発者の操作感が大幅改善。接続不安定環境でも作業継続可能に。
v2.1.176 2026-06-12
新機能
  • セッションタイトル多言語化：会話の言語でタイトルを自動生成
    日本語セッションのタイトルが英語になる問題が解消。非英語チームの UX 向上。
  • footerLinksRegexes 設定：フッターリンクバッジを正規表現でカスタマイズ
    組織ごとのフッターリンク表示の柔軟な制御が可能に。
改善
  • Bedrock 認証情報キャッシング改善：Expiration まで有効期限管理
    AWS Bedrock 利用時の認証エラーが減少。
